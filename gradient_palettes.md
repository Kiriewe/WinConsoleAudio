# Градиенты для WinConsoleAudio / Visualizer Gradient Palettes

Здесь собраны 10 классных двухцветных градиентов, которые отлично смотрятся на полосах визуализатора в консоли. Дефолтный вариант хорош, но эти комбинации помогут разнообразить внешний вид или настроить программу под тему вашего терминала.
Here is a list of 10 nice two-color gradient pairs for your visualizer. Copy the HEX values to config.txt to use them.

Чтобы включить градиент, убедитесь, что в файле config.txt заданы следующие параметры:
To use any of these, set the parameters in config.txt as follows:
```text
gradient = true
color_bottom = <цвет низа / bottom color>
color_top = <цвет верха / top color>
```

---

### 1. Sunset Vapor (Ретро-закат / Synthwave Sunset)
Классическое неоновое свечение в стиле ретровейв 80-х.
*   color_bottom = #FF2A7A (розовый неон)
*   color_top = #FFB703 (золотой закат)

---

Цвета глубоководного биолюминесцентного планктона.
*   color_bottom = #00F5D4 (бирюзовая мята)
*   color_top = #0077B6 (синяя бездна)
